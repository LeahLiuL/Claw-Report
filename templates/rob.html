ROB Trend

Each line = one selected vessel. Y axis = Remaining Onboard (ROB) in metric tonnes (MT) at each report time. Switch to Consumption mode (top-right) to see daily burn as a line. When vessels have very different ROB magnitudes (a big-value vessel flattens the others), click Scale: Log (top-right) — it compresses the Y axis so every curve stays visible. In Consumption mode, bunkering spikes (often 50–200 MT) use a separate right Y axis so they no longer flatten the 0–20 MT/day consumption line on the left. 加油 (bunkering) days show as a green ▲ at the top and are excluded from the Avg/day in Vessel Summary. Bunkering is currently inferred from ROB increases; to record explicit bunkering events, add them to rob_data/bunkering.json ({"船名": {"YYYY-MM-DD": 加油量MT}}). Use Oil to pick the product and Daily anchor to align every vessel to the same time-of-day so daily differences are comparable.

Voyage Fuel Consumption (per voyage, ROB-based)

航次号已合并方向：2630W 与 2630E 只是方向不同，属同一航次 2630（Voy 列下方小字显示包含的方向）。因此航次区间 = 该航次全部方向中最早的首港 Berth（例：CUHP 2630 取 2630W 首港 TWKEL）→ 下一航次最早的首港 Berth（2631W 首港 TWKEL）。
航次油耗 = 该区间内 ROB 的下降量之和（自动排除加油 —— 加油表现为 ROB 上升，不计入消耗）。点行首的 ▸ 可展开该航次的 rotation 明细（跨方向合并，含挂靠港所属 Voy / ETA / ETB / ETD）。B.LSFO / B.HSFO / B.MGO / B.ULSFO = 该航次《燃油添加日志》记录的分油种加油量（仅体积，不含价格），B.Total 为其合计。Total = LSFO+HSFO+MGO+ULSFO 消耗。单位 MT。状态: completed=已完成 / ongoing=进行中。

Custom Period Consumption (自选时间段油耗)

任选时间段查看某些船的油耗：选好 From / To，可用 Vessel 框按船名或代码过滤，点 Apply。油耗 = 该时段内 ROB 的下降量之和（自动排除加油）。Bunker = 该时段《燃油添加日志》记录的加油量（仅体积，不含价格）。Avg/day = 总油耗 ÷ 天数。每条船需 ≥2 条 ROB 记录才会显示。

TDR vs Actual Consumption

TDR 设计油耗曲线（来自《Vessel Daily Consumption - TCD Daily Consumption》）按航速给出各油种 标称 MT/天；实际散点仅用 NOON 报告：取相邻两封 NOON 的 ROB 差 ÷ 间隔天数，并配以后一封 NOON 的「AVG SPEED SINCE LAST NOON」（即该航段日均航速），作每日航速对比。已剔除加油日(ROB 上升)、间隔>30天、消耗率>250 MT/天。X 轴＝航速(kn)，Y 轴＝消耗率(MT/天)；实际点高于 TDR 曲线＝偏耗油。新 NOON 数据随每日刷新累积。
